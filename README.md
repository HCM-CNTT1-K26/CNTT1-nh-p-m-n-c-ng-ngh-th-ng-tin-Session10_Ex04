# Mô hình IPO trong Trang Trại Thông Minh (Dành cho người mới)

## 1. Mô hình IPO là gì?
Mô hình **IPO** viết tắt của **Input (Đầu vào) - Process (Xử lý) - Output (Đầu ra)**. Đây là cách mô tả cách một hệ thống tự động hoạt động: nhận thông tin, suy nghĩ/xử lý, rồi đưa ra hành động.

---

## 2. Ví dụ thực tế: Hệ thống tưới cây tự động

| Thành phần IPO | Giải thích đơn giản | Ví dụ thực tế trong trang trại |
| :--- | :--- | :--- |
| **Input (Đầu vào)** | Thông tin nhận được từ môi trường | Cảm biến độ ẩm đo thấy đất đang khô (độ ẩm dưới 30%). |
| **Process (Xử lý)** | Bộ não trung tâm phân tích dữ liệu | Vi điều khiển so sánh dữ liệu và quyết định cần phải tưới nước. |
| **Output (Đầu ra)** | Hành động thực tế của hệ thống | Máy bơm tự động bật lên để tưới nước cho cây. |
